# 汇报用字准则(2026-07-27 planner 定稿;PPT 文字与演讲稿共用)

**总原则(一句话测试)**:任何词,若台上被追问"这是什么"而无法用一句话解释,就不用。听众 = 具备机器学习常识、但完全不了解本项目的教授。
**适用范围(2026-07-27 扩展,用户裁定)**:不止 PPT 与演讲稿——final report 正文、以及各 agent 与用户的日常沟通,同样少用项目内部黑话;内部代号仅保留在台账、结果注记等内部档案中。

## 三层词汇

**1. 可直接用(公共 ML 术语;首次出现给半句中文注)**
扩散模型、去噪步数、蒸馏、teacher/学生、DMD2(分布匹配蒸馏)、GAN/判别器、real/fake、CFG、VBench、LPIPS(感知距离)、光流(RAFT)、随机种子、消融、预注册、迭代、存档点。

**3. 禁用(红线)**
"显著"(未做统计检验);任何"超越 teacher/老师"表述;phased/progressive DMD;内部流程词(冻结、红线、planner、验收、台账)不上台。

## 例外与句式

- **备页 B1–B6 与页脚出处**可保留代号、协议名与文件名(它们本身是溯源展示;首次出现给"描述名(代号)");正片零代号。
- 每句一个信息;**每个数字身边要有它的"怎么来的"**(集合大小 / 种子数 / 单双种子)。
- 中文为主;公共英文术语(aesthetic、LPIPS、VBench)不硬译,配一次中文括注。
- 口头可以说近似("约一到两成"),页面必须放精确数;口头与页面不得出现页面没有的新数字。
