# Reports

Active reports should be short, current, and linked to a concrete experiment config or result.

Historical weekly reports, experiment notes, and the midterm package have been moved to `archive/reports/`.

Recommended current format:

```text
reports/YYYY-MM-DD-topic.md
```

Each active report should include:

- config path
- remote log path
- checkpoint/output path
- result summary
- next action
