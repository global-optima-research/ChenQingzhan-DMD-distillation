# Archive

This directory contains historical material that should not drive new experiments by default.

## Contents

| Path | Contents |
|---|---|
| `surveys/` | Long-form background surveys moved out of the root and Task 3 mainline |
| `reports/weekly/` | Old weekly reports |
| `reports/experiments/` | Past experiment writeups |
| `reports/midterm-2026-05/` | Midterm report package |
| `reports/phase0-dmd-distillation/` | Phase 0 reports and comparisons |
| `notes/` | Old meeting notes, progress board, and personal notes |
| `scripts/wan22-i2v-2026-05/` | One-off Wan2.2 scripts from May 2026 |
| `server-patches/` | Historical FastGen patch/config snapshots |
| `project-management/` | Team assignment and planning documents |
| `artifacts/inference-videos-2026-spring/` | Historical local inference samples from 2026-04 and 2026-05 |

## Policy

Archived files are preserved for traceability. Do not copy an archived script into the active workflow unless it has been converted into a config-driven experiment under `experiments/`.
